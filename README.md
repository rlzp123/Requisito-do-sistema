# Industrial Control Tower
## Documento de requisitos do sistema

Este repositório apresenta a proposta inicial do sistema e organiza as informações que vão orientar seu desenvolvimento.

A ideia é reunir dados de pedidos, estoque, produção e logística em um só lugar, facilitando o acompanhamento da operação e a identificação de situações que precisam de atenção.

### O que você encontra neste documento

- **Apresentação e objetivos:** problema que o sistema pretende resolver e resultados esperados.
- **Usuários e módulos:** perfis previstos e principais áreas da plataforma.
- **Requisitos:** funcionalidades e características de qualidade.
- **Cenários de uso:** exemplos de situações da rotina industrial.
- **Arquitetura:** tecnologias previstas e fluxo básico das informações.
- **MVP e planejamento:** primeira versão, restrições e etapas de desenvolvimento.

### Tecnologias previstas

| Camada | Tecnologia |
|---|---|
| Frontend | React |
| Backend | Node.js e Express |
| Processamento de dados | Python, Pandas e Scikit-learn |
| Banco de dados | PostgreSQL |
| Importação | Excel e CSV |
